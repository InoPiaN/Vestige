## 구현
- `npc_life.gd`: 기존 월드 하루2880초 유지, 시각은 time/120+8을24로 나눈 나머지. 기존 시간0의 세상은 오전8시부터 보인다. 노화·재고·일기 날짜 기준은 기존 월드 일 경계를 유지한다(표시 시각의 자정과 다름).
- 소하: 07시 출근→08~18시 영업→19시 여관 앞 휴식→22시 수면. 도윤: 06시 출근→07시 나루→12시 부두 이동→13~16시 순찰→17시 나루→20시 귀가→21시 수면.
- 고정 경로의 위치를 월드 시각에서 결정적으로 보간하므로 저장/재접속/서버 스냅샷에서 동일한 위치를 얻는다. 야외 수면 스프라이트는 숨긴다. 수면 장소는 여관 쪽 지정 지점이며 침실/침대 애니메이션은 후속이다.
- Travel.places/nearby에 시각을 전달해 NPC 위치를 갱신. 구매는 서버에서 영업시간·거리·생존/조종·재고·돈을 재검사한다. 빈 상점은 부재 안내 제공. 도윤은 순찰 중에도 서신을 받고 수면 중에는 받지 않는다.
- `sky_clock.gd`: 화면430,10 크기420×60. 해/달의 궤적, 단계별 하늘색, 별·구름·능선. 숫자/바늘 없는 픽셀 그림. 기존 날짜/지역 텍스트와 대상 HUD는 오른쪽으로 이동. 지도 모달보다 위에 남는다. 화면 밖으로 구름이 새지 않도록 clip_contents 적용. 마을/숲길/나루 야간 색도 같은 시각 사용.
- `npc_activity`: 주요 일정 전환의 시각/지역/좌표를 기록. 최대96행, 긴 부재는 최근2일 구간만 추가. 개인정보/추리 권한을 위해 클라이언트 스냅샷에서는 제거한다. 실제 사건 목격이나 플레이어 접근 가능한 증언으로 간주하지 않는다.
- 저장 schema21의 선택적 필드 추가. 기존21 및 구버전 이관 보존, 기록이 있으면 형식/순서/시각 검증. 위치 자체는 시각으로 복원되므로 별도 상태 이관 불필요.
