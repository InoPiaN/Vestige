# 증거물 소유·보관·후대 발견 · 0.4.2

Codex · 2026-11-09 · `feat/evidence-items` · 기준 `9906e16`.

`evidence_items.gd`가 사건별 `object` 하나를 관리한다. 위치는 ground/house/carried이며 소유자는 계정이 아닌 생애 ID이다. 인벤토리 `evidence_items`는 이 상태에서 만든 표시용 사본으로 로드·이동 시 재생성한다. 현장/집에서 F를 누르면 수집, 집 근처 소지품 버튼으로 보관한다. 죽으면 소지 중인 증거만 실제 사망 위치에 떨어지며 집에 보관한 증거는 유지된다. 수첩 관찰과 물리적 소유는 별개다. 증거를 타인이 가져가도 기존의 현장 흔적 관찰로 조사를 이어갈 수 있다.

기존 살해 데모 저장도 버전 3으로 자동 이관되어 조각 하나를 얻는다. 이전 앱으로 버전 3 저장을 열지 않는다. 사용자 저장을 초기화하거나 테스트에 사용하지 않았다. 다음 생애는 빈 수첩에서 다시 시작한다. 집의 F는 보관된 증거를 회수하므로 보관 직후 다시 F를 누르면 본인이 회수한다. 별도 보관함 선택 화면은 아직 없다.

UI 변경은 기존 인벤토리의 동적 아이템 정의/조각 아이콘/보관 버튼에 한정된다. Claude UI 변경과 병합할 때 `Items.definition(person,id)` 호출을 유지해야 한다. `main.gd`는 변경하지 않았다. 공개 GitHub의 새 Claude 커밋은 이번 시작 시 없었다.

검증: 신규 14개 포함 총 106개 검사, 첫 여정 30/60Hz, 실제 ENet 클라이언트 수집→집 보관→회수 통과. 테스트 월드는 /tmp 아래 생성하고 로컬 시험 서버를 종료했다. Mac 0.4.2 ad-hoc 서명 및 headless 메뉴 기동 확인. Windows 0.4.2 export/PE 형식 확인, Windows 실기 및 시각 QA는 미실시. 샌드박스 headless 실행의 macOS 인증서 경고와 저장 실패 회귀 시험의 의도된 오류 외 스크립트 오류 없음.

실행: 기본 workspace builds/Play-Witness.command → 0.4.2. Windows builds/windows-0.4.2/Play-Witness.cmd. 기존 플레이 상태는 유지한다.

다음 추천: 일반 물품을 집에 넣고 꺼내는 보관함, 개별 장비 데이터, 여러 주택/상속. 현재 실물 증거는 정해진 살해 사건의 조각 하나만 지원한다. 다중 저장 작성자/Steam Cloud 충돌과 서버 중단 직전 저장 보장은 후속 범위다.
