# 목격 증언과 용의자 지목 · 0.4.1

Codex · `feat/witness-case` · 기준 `927ad6e`.

`-- --witness-demo`로 시작하는 “장터의 마지막 장부”는 `witness-demo.json`을 사용한다. 별도로 만든 사건의 시작 상태에서 운송인이 집주인에게 치명상을 가한다. 사건 발생 시 미라에게서 보이는 거리와 건물에 가려지는지를 검사하고 소매 장식과 날짜를 보존한다. 집 장부와 현장 조각, 증언을 확보한 조사자가 묘지에서 두 용의자 중 한 사람을 지목한다. 오답은 사건을 열린 상태로 두며 정답은 묘비와 수첩에 기록한다.

검증: 신규 15개, 기존 77개 검사와 첫 여정 30/60Hz 시뮬레이션 통과. ENet 클라이언트가 미라에게 근접해 증언만 받는 시험 통과. Mac 배포 앱 체험 시작 확인. Windows는 빌드와 형식 검증을 마쳤으며 실기 플레이 확인이 남아 있다.

현재 사건은 구성된 한 건이며 미라는 정해진 위치에서 증언한다. 일반 월드의 자율 범죄, 이동하는 다수 목격자, 목격자가 없을 때의 대체 증거는 후속 범위다. 기존 소율 체험은 기존 실행 옵션으로 이어진다.
