# 제작 숙련도 · 0.5.4

Codex · 2026-11-10 · feat/crafting-mastery · 기준84d1eb7.

사용자 작업 규칙: **새 작업마다 먼저 관련 대작 게임을 조사하고, Vestige 적용안을 제안해 승인을 받아야 한다.** 이번 분야별 숙련도/4단계/품질확률/부재 제작/일기는 이미 승인받았다. CRAFTING_REFERENCES.md에 공식 출처와 승인 범위를 기록했다. 다음 기능 구현을 임의로 시작하지 말 것.

craft_mastery.gd는 사람별 craft_xp={smithing,handicraft,herbalism}와 확률/단계/경험치 함수를 제공한다. 단계누적0/100/400/1000, 확률70/20/10,65/23/12,57/27/16,45/30/25. 철검12XP/난이도1, 도구10/1, 찻잔8/0, 붕대8/0, 차10/1. 실제 경험치=floor(기본XP/(1+max(단계-난이도,0))), 최소1, 전체1000상한. 실제 제작 완료에만 award, 수선/거래/부족 재료/재고한도/잘못된 ID에는 없음. 장인도 제작 가능하나 추가XP0.

Quality.roll의 세 번째 인자로 기본 확률표를 받는다(기존 호출 기본값70/20/10 유지). 실제 제작은 Mastery.rates 결과를 전달하며 찻잔 보정은 rates에서 일반→대성공으로 옮긴다. 난수 소비2회 유지, 제작 전 단계로 roll 후 award. 공격력 구간/기존 장비 성능은 유지. world.forge_sword가 직접/부재 둘 모두 동일 성장 처리. 기존 부재 work는 철검만 지원하며 새 생활공예/조제 정책은 추가하지 않았다.

award는 단계 상승 시 p.events에 기록, 기존 날짜 처리에서 journal에 묶이고 사망시 books에 남는다. 새 인물은XP0, 자동 상속하지 않는다. 저장10은 각 XP의 유한정수0..1000과 정확한 분야 키를 검증한다. 기존1~9는 outfit에서XP0 추가. 공용skill은 전투훈련/과거작업이 혼합되어 있으므로 변환하지 않고 기초 숙련으로 보존한다. snapshot에서 타인의craft_xp는 제외한다.

UI: 작업대 선택 제작법의 분야/누적XP/다음단계/이번획득XP/최종확률. 대장간은 E 안내에 같은 정보 표시. J에 전 분야 진행. 기존 작업대 레이아웃을 소폭 조정했으므로 Claude UI 통합시 해당 데이터 갱신 연결 유지. 새 원격 Claude 변경은 시작시 없었다.

검증: 신규29 포함277개 검사와 첫 여정30/60Hz, ENet 제작→견습104XP→재료없는반복XP불변·일기. 저장/구버전/잘못된XP/사망후계자/직접vs부재/도구보정/제작전판정 검사. scripts/render_mastery.gd는 실제 craft_button 신호로104XP와양품23% 표시 검증 후 전후·대장간 화면 렌더링. 임시 UI 저장을 삭제하며 실제 사용자 저장은 건드리지 않는다. 시험 서버 종료.

체험: -- --mastery-demo, Play-Mastery.command/cmd, 별도 mastery-demo.json. 약초96/대장400/공예1000인 시험 인물이며 붕대1개로 견습 상승. 일반 신규 인물은모두0. 기존 실행기도0.5.4로 연결.

다음 후보는 경제/경험치 균형과 부재 제작 선택 확장 또는 제작 노트 전승. 모두 자료 조사→사용자 승인 후 진행. 장비/주택/Steam 등 큰 미완성 범위는 로드맵 참조. 누적 기능 브랜치이며 main 병합은 별도다.
