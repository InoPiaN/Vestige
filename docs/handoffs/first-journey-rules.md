Codex · 2026-11-06 · `feat/first-journey-rules` · 애니메이션 커밋 `aad0aa5`에서 분기.

초당 30회와 60회로 월드를 진행했다. 마을 출발부터 철광석 2개 채굴, 철검 제작, 늑대 처치, 유적 조사, 저장·재접속, 서재 귀환과 다음 날 일기까지 실제 이동·상호작용 규칙으로 확인했다. 처치 보상은 은화 8, 조사 보상은 유물 1개이며 재조사 후에도 그대로다.

재방문 시에는 수호 늑대 생존 여부보다 인물의 조사 기록을 먼저 확인한다. 부활한 늑대는 새 공격 예고를 시작한다. 재현 검사는 `desktop/tests/test_first_journey.gd`에 있다. 기존 규칙·애니메이션·커스터마이징·인벤토리 검사 44개도 통과했다.

화면과 조작감은 수동 플레이 검증 대상으로 남아 있다. 다음 게임 규칙 작업은 저장 손상 시 백업 복원과 부재 시간 중복 반영 방지다.
