# 집 작업대 제작·수선 · 0.5.1

Codex · 2026-11-10 · `feat/home-crafting` · 기준 `b9c10a4`.

`home_crafting.gd`에 제작법·자격·재료/도구/불/완성품 한도 검사와 수선/소비품 효과를 모았다. world.act의 craft_home/repair_gear/use_crafted에서 처리한다. 집 table 근처에서만 제작·수선할 수 있으며 소지 재료만 소비한다. 천+약초→붕대(hp45), 천+못2→수선 도구, 찻잔+천→고친 찻잔, 약초+찻잔 도구+불→약초차(hp20/stamina40). 찻잔 도구는 소비하지 않는다. 생활 제작에 기존 전투/대장간 숙련도를 임의로 올리지는 않는다.

컨테이너마다 `gear_condition: {gear_id: 0..100}`를 추가했다. Storage.reconcile은 새 ID의 내구도 100을 부여하고 없어진 ID를 제거한다. 집 보관/회수, 사망 이전, 유품 회수는 ID와 상태를 함께 이동한다. 철검으로 적에게 명중할 때 5를 소모한다. 내구도 0은 공격력 9이며 1 이상은 22. 검을 삭제하지 않고 작업대의 도구로 40 회복한다. 다른 장비는 현재 마모하지 않는다. world.weapon_damage를 실제 전투와 상태 설명에 공유한다.

저장 버전 7. 1~6 이관 시 인물·집·유품의 장비에 100을 추가한다. 기존 내구도가 있으면 유지하며 최신 저장의 범위/키 일치 검증을 한다. 사용자 저장을 테스트에 쓰거나 초기화하지 않았다. 단일 저장/백업 회복과 기존 원자적 파일 교체 경로를 유지한다.

UI: `crafting_panel.gd`에서 재료 보유량, 불/도구 조건, 제작 불가 이유, 수선 대상 철검을 표시한다. main에서 E 작업대 진입과 일시정지/이동 차단/ESC/다른 창 전환을 연결했다. 인벤토리에 붕대/차 사용 및 철검 내구도 표시. 네트워크 갱신 시 수선 선택창을 매번 재생성하지 않도록 장비 상태 서명을 사용한다. Claude 통합 때 해당 연결을 보존해야 한다. 이번 시작 시 새 원격 Claude 커밋 없음.

체험: `-- --craft-demo` 또는 builds/Play-Craft.command. 독립 craft-demo.json. 재료 꾸러미와 내구도 35 철검으로 시작한다. 체험 실행 분기는 기존 home/remains/witness/investigation 저장 경로를 유지하며 정리했다. 기존 가구의 식탁은 이번 버전에서 작업대로 전환했다.

검증: 신규 26개 포함 203개 검사와 첫 여정 30/60Hz. 실제 ENet 수선 도구 제작→정확한 검 수선→도구 없는 반복 요청 차단 통과. /tmp 테스트 월드와 서버를 사용하고 서버 종료. scripts/render_crafting.gd로 화면 렌더링/육안 검수. Mac·Windows 0.5.1 빌드, Mac ad-hoc 서명 및 headless 메뉴 기동, Windows PE 형식 확인. Windows 실기 미검증.

한계: 현재 천/못/찻잔 재공급은 없으며 서랍 내용은 유한하다. 소모된 검 대신 새 철검 제작도 가능하다. 재료 조달·거래·생산 경제 및 생활 제작 숙련도 설계가 다음 우선순위다. 다른 장비 내구도 효과·품질·강화, 다중 주택/상속/가구 이동, 저장 충돌/Steam Cloud와 UI 브랜치 통합은 후속 범위다. 이번도 누적 기능 브랜치이며 main에 병합하지 않았다.
