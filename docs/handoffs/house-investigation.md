# 집과 사망 기록 조사 · 0.4.0

Codex · `feat/house-investigation` · 기준 `e52acbd`.

언덕집은 (7,13)의 고정 필지다. 문 앞 E로 은화 8개를 지불하고 책장에 일지를 보관한다. 집주인이 죽으면 생애 ID에 연결한 사건을 월드에 남긴다. 다음 인물은 F로 집과 현장에서 각각 증거를 찾고 묘지에서 사인을 확정한다. J 조사 수첩은 인물별로 저장한다. 주인이 생전에 집에 둔 기록과 현장에서 회수한 마지막 기록의 열람 시점이 다르다.

분리된 체험 월드는 `-- --investigation-demo`로 시작한다. Mac 빌드 옆의 Play-Investigation.command 또는 Windows의 Play-Investigation.cmd를 사용한다. 플레이 기록은 investigation-demo.json에만 남는다.

버전 1 저장은 버전 2로 올린다. 기존 일기와 묘지는 보존하며, 과거 사망에 단서를 소급 생성하지 않는다. 새 버전의 저장은 0.4.0에서 이어서 사용한다.

검증: 조사 검사 17개, 기존 규칙/저장/외형 등 60개 검사와 첫 여정 시뮬레이션 통과. ENet 시험 클라이언트가 집으로 이동해 실제 서버의 기록을 받는 것과 미발견 사인이 클라이언트로 가지 않는 것을 확인했다. Mac 앱은 체험 모드 시작 검증, Windows는 빌드·파일 형식 검증을 완료했다.

Claude 통합 시 main.gd에서는 F 조사, 기존 J/서재 열람, 상호작용 안내와 스냅샷 필터 호출을 비교한다. pixel_world.gd에는 언덕집과 근접 현장 표식만 추가했다. 단서·소유권 규칙은 investigation.gd에 있다. 다음 범위는 목격 증언과 NPC 사건이다.
