# 월드 저장 복구 인계

2026-11-06 · Codex · `feat/world-save-recovery` · 기준 `121ef35`.

원본과 백업은 기존 버전 1 JSON 형식을 사용한다. 원본이 없거나 필수 게임 기록을 읽을 수 없으면 정상 백업에서 복원한다. 더 높은 버전의 원본 또는 복구할 수 없는 파일은 그대로 두고 게임 진입을 중단한다. 싱글은 부재 결과와 처리 시각을 디스크에 함께 기록한 후에만 플레이를 시작한다. 전용 서버는 중지된 시간만큼 세계를 진행하지 않는다. 장기 부재 중의 자연사는 실제 마지막 활동일에 기록한다.

`test_save_recovery.gd` 16개 검사와 기존 44개 검사, 30/60Hz 첫 여정 시뮬레이션을 임시 파일로 확인했다. 쓰기 실패 검사의 오류 로그는 임시 기록 경로를 차단해 의도적으로 발생시킨 것이다. 백업 복원은 마지막 정상 스냅샷 시점까지 보장하며 이후 수동 행동은 복구되지 않을 수 있다. 동일 경로의 복수 동시 작성자와 클라우드 충돌 해결은 후속 작업이다.

Claude와의 통합 시 `main.gd`에서 서버 시작·싱글 진입·종료 처리만 비교하면 된다. 저장 규칙은 `world.gd`, 파일 검증과 교체는 `world_store.gd`에 있다.
