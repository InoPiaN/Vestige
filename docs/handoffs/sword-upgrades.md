# 철검 강화 · 0.5.8

Codex · 2026-11-11 · feat/sword-upgrades · 기준606a15b. 소스 작업 위치 /private/tmp/vestige-gear-provenance (같은 격리 작업트리에서 새 브랜치). 원격 fetch에서 추가 변경 없음. main 병합 별도.

사용자 규칙: 매 새 기능은 관련 대작 게임 조사 → 적용안 → 승인 후 구현. Elden Ring의 재료/대장장이 강화와 ESO의 개별 기존 장비 선택을 참고한 +1~+3 제안을 승인받았다. 확정 성공, 단계당공격+2, 제작자/품질 유지와 강화 이력, 보관/사망/회수 보존까지 승인 범위. 비용은 초기 수치 철광석2/4/6·은화4/8/12로 정했다. 새 버전 실행 파일 검증 후 이전 버전 실행 패키지를 삭제하고 최신만 유지하라는 사용자 요청도 지속 적용한다. 저장·복구 파일과 소스/Git 이력은 보존한다.

## 데이터 / 액션

gear_quality[id].upgrade=0..3, attack은 원래 제작 공격력 그대로. craft_quality.attack이 기본공격+2*강화단계를 계산하며 world.weapon_damage는 내구도0이면 여전히9를 반환한다. forge_sword 신규품질롤 upgrade0, Storage.reconcile은 구버전 모든 개별장비에0을 부여한다. 저장14는 단계정수/범위/철검외0을 검증하고 1~13을 이관한다. 집/유품은 기존 quality Dictionary 이동 경로를 그대로 사용한다.

sword_upgrade.gd: 살아 있고 직접 조종 중이며 마을 대장간거리<2인 경우만 강화. upgrade_sword 값은 gearID|expectedLevel. 현재단계 불일치 시 무소비로 거절해 중복 요청의 이중 지출을 막는다. 실제 소지철검/상한/철광석/은화를 검사한 뒤 비용차감·단계상승·upgraded 이력·인물 메모를 한 번 적용한다. 원래제작자/품질/내구/제작XP/품질난수는 유지한다. 부재 자동강화·강화 수선·판매가 보정은 미포함.

## UI / Claude 통합

forge_panel.gd는 기존 crafting_panel의 label/button 공통함수를 재사용하되 ready/refresh를 재정의한다. 대장간 E는 이제 이 창을 열고, 새철검제작 버튼은 기존 interact 액션을 호출한다. 기존 world의 직접 interact 제작과 자동생산 규칙은 유지하여 이전게임/테스트 흐름을 보존한다. 강화할검 목록과 전후공격/비용/소지재료/내구를 표시하며 불가하면 버튼 비활성화. 장비/소지품명에 +N, 설명과 장비공격력에 합산값 표시. 단일창은 세계정지, 멀티는 계속흐르며 서버가 실제상태를검증한다. 다른창/ESC 열기 시 forge도 닫는다.
