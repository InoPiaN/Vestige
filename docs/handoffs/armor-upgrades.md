# 방어구 강화와 도트 효과 · 0.5.12

Codex · 2026-11-12 · codex/armor-upgrades · 기준 ec2681e. 실제 작업트리 `/private/tmp/vestige-gear-provenance`, 원본 checkout은 덮어쓰지 않는다. Claude UI 병행, 원격 fetch 추가변경 없음. 사용자 승인: ESO의 개별장비 개선 참고, 가죽/철제 +1~+3 확정강화, 비용/방어 전후 비교, 테두리→빛→입자, 제작자·품질·내구·유품 보존. 새 기능은 조사→제안→승인 절차 필수.

## 구현

`armor_upgrade.gd` 내부 규칙: COSTS 가죽 hide1/2/3+cloth1/2/3, 철제 ore2/4/6+hide1/1/2, GOLD 공통4/8/12. `upgrade_armor` 액션 `id|expectedLevel`. 살아 있고 직접조종, 마을 대장간2미만 거리, 소지개별ID/최대단계/재료/돈 검증 후 한 번 소비한다. 중복 오래된 요청은 비용무소비. 강화는 품질/기본방어/제작자/내구/RNG/XP를 변경하지 않는다. `gear_quality.upgrade`를 올리고 `upgraded` 이력과 인물 메모를 남긴다.

`armor_stats.rating(p,id)`는 제작 기본방어+강화단계. `defense(p)`는 실제 착용하고 내구>0일 때만 rating, 파손0. 회피 가죽32/철제38·최소피해1·피격내구5는 유지. `items.definition` 갑옷 이름에 +단계와 증가한 방어 설명, main 몸통 선택과 상태도 같은 계산을 사용한다. 기존 수선은 강화를 보존한 채 내구만 회복한다.

`forge_panel.gd`는 철검/갑옷 공통 개별장비 선택. 선택한 종류에 따라 기존 철검 강화 또는 새갑옷 강화로 전달. 갑옷 필요/소지재료·은화·강화전후방어·파손/회피 설명. 최초 소지 철검이 있으면 기존 철검 선택 흐름을 유지한다. 방어구 제작창은 기존대로 별도 버튼. 새 모달을 늘리지 않았다.

`character_detail.gd` 실제몸통ID/종류의 강화만 읽는다. +1 가장자리, +2 옅은 청록과 추가강조, +3 시간에 따라 이동하는 작은입자. 상하좌우 압축/미러와 피격색 적용. 뒤에서 망토가 덮으면 갑옷효과도 숨김. 기본의복/갑옷해제는 잔상없음. 파손 때도 강화외형은 남으며 방어0은 UI에서명시. 사망은기존sprite없음. 맵해상도/캐릭터크기 변경없음.

저장17. 1~16 기존저장 이관은기존품질/수치/진행보존. 저장검증은17부터 갑옷upgrade0~3허용, 그외의복0, 기본defense는기존품질범위별도검증. 기존16이하에는갑옷강화불허, 미래18보호. 보관함/유품의같은ID 메타데이터 이동경로를그대로사용한다.
