# 캐릭터·장비 디테일 시안 · 2026-11-12

브랜치 art/character-detail-preview, 기준0ad157e(0.5.8 강화). 사용자: 맵 품질은 유지하고 캐릭터/장비 도트 해상도를 높여 디테일을 원함. 같은 화면 크기에서 약2배 밀도로 기본캐릭터/철검 비교시안을 먼저 보여주고 확인 후 전체동작으로확장하는 절차를 승인받았다.

scripts/preview_character_detail.gd는 검토 전용 Godot 렌더러. 기존 portrait와 독립적으로 그린 정면 캐릭터를 나란히 표시한다. 기존픽셀6화면픽셀/새픽셀3화면픽셀. 작은 얼굴/머리 결/옷 주름, 어깨금속, 가죽판과버클, 칼날면/손잡이/감개, +3칼날빛/입자의정지시안. artifacts/art/character-detail-preview.png. GPU렌더링확인, 사용자저장미사용.

강화이펙트는 이전 적용안 승인됨: +1은빛, +2푸른빛과간헐적입자, +3선명한빛과짧은공격잔상. 참고: Lineage II Classic 공식 패치노트의 강화무기 발광 https://www.lineage2.com/en-us/news/lineage-ii-classic-launch-patch-notes . 이번시안에는+3의정지발광만표현했으며 동작/시간애니메이션은미적용이다.

제작시안 확인 전까지 실제 pixel_world.gd와 portrait.gd는변경하지않았다. 새실행버전없음, 현재0.5.8유지. 시안승인후에만 4방향·걷기·공격·피격·회피·외형옵션·장비레이어·단계별효과를 통합하고 맵해상도를유지한채 캐릭터를별도고해상도레이어로렌더링할계획이다. 기존맵과동일한저해상도SubViewport에반픽셀로그리면최종샘플링에서디테일이사라지므로, 레이어와뷰포트구조부터점검해야한다.
