## 승인 범위

사용자에게 다키스트 던전의 철수 판단, 길드워2의 이동/회피/기술 전투를 조사해 제시했고, 새 적2종·원정 의뢰2개·전리품·대상 선택·기록/저장/멀티 검증을 승인받았다. 이번은 기존 마을 지도의 북동/남동 숲을 활용한 고정 원정이다. 별도 지역/절차 생성은 후속이다. 5~10분은 초기 목표이며 실제 사용자 플레이 시간/난이도는 미검증이다.

## 구현 구조

- `expedition.gd`: 세계 `enemies`(boar/wraith), `field_loot`; 인물 `expeditions`(warrior/hunter: new/active/ready/done), `target_enemy`.
- 기존 `wolf` 데이터와 첫 여정은 유지. `all/selected/cycle`로 늑대와 새 적을 통합 선택한다. 살아 있는8칸 이내 적 중 현재 선택을 유지하고, 불가하면 가장 가까운 적으로 전환한다. 공격 범위/건물 시야는 기존 `Professions.strike`에서 따로 검증한다.
- TAB으로 대상 전환, 상단 이름/체력과 대상 원형 표시. `_input`에서 처리해 사이드바 포커스 때문에 TAB이 먹히지 않는 문제를 방지하며 모달 안에서는 정상 UI 탐색을 허용한다.
- 들멧돼지(26,3): 체력95, 1초 예고 후 고정 방향3.2칸 돌진, 선분 반경0.7 물리 피해24. 공격 후2.2초 재사용. 돌진 잔상 표시.
- 망령 궁수(27,16): 체력75, 1.2초 조준 후 고정 선분 반경0.35 물리 피해18. 재사용 중 가까운 인물에게서 물러남. 공격 예고 중 움직이면 조준선에서 벗어날 수 있다.
- 기본 감지3.8칸/예고 중5칸, 원위치6칸 밖 또는 마을 쪽으로 도망가면 추격 중단/복귀. 새 적은 직접 조종 중인 생존 인물만 공격한다. 회피·갑옷·방어 자세와 기존 사망 처리 사용. 둔화는 추적/후퇴 이동속도에 적용하며 돌진 거리/조준 시간은 바꾸지 않는다.
- `Professions.strike`는 선택 적에 기존 무기 피해·기술·내구·명중 숙련 적용. 새 적 사망 후 월드1일(2880초) 뒤 재생성. 의뢰와 남은 전리품은 초기화하지 않는다.
- 교관 라온: 북쪽 숲길의 위협, 들멧돼지1마리, 보고 은화14. 사냥꾼 세린: 남쪽 숲의 잿빛 화살, 망령 궁수1마리, 보고 은화16. 해당 길 입문 완료 후 수락 가능. 수락 후 직접 처치해야 ready, 해당 스승 근처에서 보고하면 done과 보상. 생애별1회, 반복 보고/원격 보고 차단.
- 공유 세계는 마지막 일격을 가한 인물만 의뢰 진척, 현장 전리품은 먼저 회수한 인물이 소유. 화면/README에 명시. 파티 공동 진척/개인 드롭은 미구현.
- 현장 전리품: 들멧돼지 가죽2/엄니1, 망령 잿가루2. R로 근처 한 더미 회수. 아이템별 소지 한도만큼 부분 회수하며 남은 것은 현장에 보존/저장한다. 원격·사망·부재·실내 회수 불가, 중복 회수 불가. 가죽/엄니/잿가루 판매가는1/3/2은화.
- 아이템 카탈로그에 추가하여 기존 인벤토리/집 보관/판매/사망 유품에 연결. 원정 수락·처치·회수·귀환 보고를 활동 메모와 일기에 남긴다.
- `expedition_art.gd`: 코드 기반 도트로 새 적, 예고선, 잔상, 체력, 전리품 가방과 대상 표식. 지도에 적 실루엣이 보이도록 해당 숲의 장식 나무 일부 비움.

- 저장20: 기존1~19 이관 시 새 적/빈 전리품/미수락 의뢰만 추가. 기존 진행·장비·일기 유지. 미래21 보호. 적 수치/좌표/타이머·전리품·의뢰 상태·선택 ID 검증. 타인의 의뢰/대상 선택은 서버에서 비공개 처리.
