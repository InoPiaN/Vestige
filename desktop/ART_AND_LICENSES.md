# 아트와 런타임 출처

`pixel_world.gd`의 지형, 나무, 집, 여관, 대장간, 서재, 묘비, 인물, 늑대와 소품은 이 프로젝트를 위해 코드로 직접 작성한 픽셀 도형입니다. 외부 게임의 이미지나 스프라이트를 가져오지 않았습니다. 고정 시드로 지형 질감을 만들며 480×320 월드 화면을 최근접 방식으로 2배 표시합니다. 후속 제작에서는 같은 팔레트와 기준점을 사용하는 스프라이트 시트로 대체할 수 있습니다.

한글 UI는 실행 OS에 설치된 시스템 폰트를 사용합니다. 폰트 파일을 추출하거나 번들에 포함하지 않았습니다. 출시 시 일관된 글꼴이 필요하면 배포 가능한 라이선스의 폰트를 별도로 선정해야 합니다.

실행 파일은 Godot 4.5.1 공식 템플릿을 사용합니다. Godot는 MIT 라이선스이며 엔진과 제3자 구성 요소의 고지는 공식 라이선스 페이지에서 확인할 수 있습니다:

- https://godotengine.org/license/
- https://github.com/godotengine/godot/blob/4.5.1-stable/LICENSE.txt
- https://github.com/godotengine/godot/blob/4.5.1-stable/COPYRIGHT.txt

이 시제품에는 생성형 AI API 호출, 외부 분석 도구, 외부 유료 에셋이 없습니다. 설치형 앱의 싱글 모드는 외부 네트워크 연결을 요구하지 않습니다.
