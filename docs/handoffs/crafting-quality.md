# 제작 품질과 대성공 · 0.5.2

Codex · 2026-11-10 · `feat/crafting-quality` · 기준 `490e61e`.

craft_quality.gd는 world.craft_rng의 저장 가능한 난수 흐름을 사용한다. 일반70/양품20/대성공10%, 철검 공격력20~24/24~26/27~29. 유효한 제작에만 2회 진행한다. 실패한 재료/한도/도구 검사, 수선, 아이템 이동은 진행하지 않는다. 서버 snapshot에서 craft_rng를 제거한다. 보안용 난수 시스템은 아니며 리플레이 가능한 게임 규칙이다.

장비별 gear_quality[id]={tier,attack}를 추가했다. 기존 gear_condition과 함께 집/소지/유품 사이에서 이동하고 중복 소유를 만들지 않는다. Storage.reconcile의 누락된 기존 장비 기본값은 일반/22(비무기0)다. 직접 대장간 제작 및 부재 work 모두 world.forge_sword로 실제 ID를 만들고 품질을 부여한다. 직접 제작은 새 검을 착용한다. 공격은 실제 품질 수치, 내구도0일 때9를 사용한다. 수선은 내구도만 바꾼다.

Items는 기본 카탈로그에 bandage/repair_kit/mug/herbal_tea의 _fine/_great를 생성한다. 품질별 묶음은 분리하지만 family_quantity로 제작/회수 한도를 합산한다. 수선 도구와 찻잔은 best로 좋은 품질부터 선택한다. 붕대45/48/54, 수선40/44/50, 차 hp20/22/25 + stamina40/44/50. 양품/대성공 찻잔은 약초차 대성공 확률+2/+5%p, 일반 확률에서 차감하고 양품20은 유지한다. 장비별 변동과 소모품 품질별 고정 수치를 구분한다.

저장 형식8: 기존1~7의 장비는 무작위로 업그레이드하지 않고 일반22로 이관하며 내구도를 유지한다. 최신 저장은 품질 키/등급/공격력 범위와 난수 상태를 검증한다. 기존 사용자 저장을 테스트에 쓰거나 초기화하지 않았다.

UI: 인벤토리 세부에 품질·실제 공격력·내구도, 품질별 글자색, 더 많은 품목을 위한 스크롤. 작업대는 실제 찻잔 보정을 반영한 확률을 표시한다. Claude 통합 시 Items.definition/family_quantity 및 인벤토리의 gear_quality 갱신 서명을 유지할 것. 새 원격 Claude 변경은 작업 시작 시 없었다.

검증: 신규21개 포함224개 검사와 첫 여정30/60Hz. 실제 ENet에서 대성공 도구 제작→철검50회복→도구없는 재요청 무효·난수 비공개 통과. 테스트에서 기본 품질 효과를 보는 기존 crafting 시나리오는 seed19로 고정해 무작위 실패를 제거했다. 품질 테스트는 별도로 실제 제작/보관/사망/후대회수/재접속/기존저장/부재제작을 검사한다. /tmp 시험 서버 종료, scripts/render_quality.gd로 화면 렌더링/육안 확인.

체험: Play-Quality.command / Play-Quality.cmd / -- --quality-demo. 독립 quality-demo.json이며 고정 예시 seed8로 실제 대장간 제작을 세 번 수행해 모든 품질의 예시를 제공한다. 일반 월드의 확률을 바꾸지 않는다. Mac·Windows0.5.2 빌드 완료, Mac ad-hoc 서명과 headless 메뉴 기동 및 Windows PE 형식 확인. Windows 실기 별도.

다음: 생활 제작 숙련도와 확률 보정, 재료 조달/거래/경제, 품질이 거래 가치에 미치는 영향. 다른 장비는 아직 제작하지 않으며 품질 성능도 없다. 누적 기능 브랜치이며 main 병합은 별도다.
