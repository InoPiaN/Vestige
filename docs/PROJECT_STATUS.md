# Vestige 전체 기능 점검표

2026-11-13 · 0.5.13 · 코드/테스트/실행본 기준. “구현 완료”는 현재 시제품의 제한된 범위에서 작동한다는 뜻이며 Steam 출시 품질을 뜻하지 않는다. 버전별 과거 로드맵의 미완료 체크보다 이 문서를 우선한다. 전체 완성률은 콘텐츠 규모/출시 기준이 확정되지 않아 수치로 산정하지 않는다.

## 2. 기본은 있으나 최종 목표까지 확장이 필요한 기능

- **탐험/전투:** 현재 작은 고정 마을·근교·예배당과 제한된 적/보상. 여러 적·무기종·기술·보스·던전·의뢰·난이도·원정/귀환의 반복 재미가 필요하다.
- **지속되는 NPC 생활:** 단순 이동과 일일 결과 계산이다. 자율 욕구·관계·전문직·생활 일정·경로 탐색·위기 도주/구조·사건 생성은 미완성이다. 싱글 종료 중 프로세스가 계속 도는 것이 아니라 재접속 시 경과 시간을 계산한다. 멀티는 서버가 실행될 때 흐르고 서버 중지는 정지다.
- **일기와 추리:** 활동 기반 정형 기록과 구성된 사건 시나리오가 작동한다. 모든 자유 플레이 사건을 설명하는 자연스러운 장편 일기, 여러 증인·거짓말·대체 증거 경로·임의 살인 사건 자동 추적은 미완성이다. 생성형 AI 일기는 연결되어 있지 않다.
- **주거/유산:** 고정집1개와 사망자의 집·유품 발견이다. 자유 건축/여러 필지/소유권 상속/임대/철거 시 자료 보존을 갖춘 부동산 시스템은 아니다.
- **성장/수명:** 제작 분야3개와 단순 훈련이 있다. 전투직업·전문화·경지 돌파·수명 연장은 미구현이다. 현재 일반인20세→60세, 현실48분/게임1일 기준 자연사까지480일이라는 규칙은 있으나 실제480일 운영 검증은 하지 않았다.
- **경제:** 고정 재고·가격·제작·강화·수리·거래가 연결되었다. 장기 자원 공급/소모·수익 균형, 동적 수요·흥정·상인 성격·플레이어 거래는 후속이다.
- **장비/아트:** 철검과 몸통갑옷2종 중심이다. 다양한 무기/방어구·세트·부위·종족/체형·최종 애니메이션/효과/음향이 필요하다. 후드/망토는 현재 외형 장비다.
- **공유 월드:** 로컬 ENet 시제품이다. Steam 계정 인증/친구 초대, 인터넷 연결 편의성, 복구·보안·부하·운영도구·백업정책과 장기 안정화가 남았다.

## 3. 아직 구현해야 하는 핵심 목표

- [ ] 여러 마을, 지역 이동, 발견 지도/안개, 지역별 재료·NPC·사건·의뢰
- [ ] 절차적 던전/탐험 콘텐츠, 다양한 적·보스·직업 기술·마법
- [ ] 직업 자유 성장, 경지 돌파 및 수명 연장, 종족별 차이
- [ ] 토지/다중 주택·건축·증축·가구 배치·임대·상속/유산 관리
- [ ] 제작법 발견·연구/분해·제작 노트 전승
- [ ] 자율 NPC 관계/기억/생활과 실제 월드 사건에서 발생하는 추적 가능한 죽음
- [ ] 부활 직업·아이템·의식, 부활 비용과 유품/소유권/생애 처리
- [ ] 멀티 출입/도난/범죄/PvP 규칙과 공정한 기록 공개 권한
- [ ] 싱글 월드 관리/규칙 설정/테스트 도구의 정식 UI

## 4. Steam 출시 전 필수 작업

- [ ] Windows 실제 실행·저장·재실행·장비/전투 조작 검증과 최소사양 측정
- [ ] 키 변경·음량·화면·접근성·튜토리얼·오디오·최종 UI/아트
- [ ] Claude 작업 브랜치 확인/통합 및 통합 후 화면/플레이 회귀 검증
- [ ] 장시간/대량 기록·NPC·유품·접속 부하, 크래시/저장 복구/서버 재시작 검증
- [ ] Steamworks 신원/친구 초대/업적/싱글 Cloud 및 충돌 처리
- [ ] 배포·업데이트 방식/라이선스/스토어 소재·가격·출시 범위 결정
- [ ] 실제 사용자 플레이테스트와 밸런스/동선/가독성 개선
- [ ] Steam 구매/등록/게시/출시는 별도 명시적 승인 후 수행

## 5. 권장 다음 순서 (미승인 제안)

1. **지금 시제품 전체를 직접 플레이하며 동선/설명/불편 확인.** 기능별 체험 외에 새 인물→채집→제작→전투→수리→판매→부재→사망/기록 발견이 이어지는지 점검한다.
2. **첫 완결 원정 콘텐츠.** 새 적/보상/귀환 의뢰를 묶어 반복 플레이 이유를 만든다.
3. **두 번째 마을과 지도 발견.** 여행/지역 차이를 게임의 핵심 흐름으로 연결한다.
4. **직업·경지 또는 주택·상속 중 중심축 선택.** 두 큰 시스템을 동시에 넓히기보다 플레이 흐름에 맞춰 단계적으로 구현한다.
5. **자율 사건·추리·부활, 멀티 운영과 Steam 준비.** 앞 단계의 실제 플레이 데이터를 바탕으로 확장한다.

새 기능은 기존 대작 사례 조사→Vestige 적용안 제안→사용자 승인 후 구현한다. 이 문서의 권장 순서는 새 기능 구현 승인을 대신하지 않는다.
